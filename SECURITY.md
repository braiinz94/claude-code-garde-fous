# Sécurité

Ces mods sont des garde-fous : une faille qui permet de les contourner (envoi sans confirmation, secret non repéré dans un format courant, journal falsifiable sans que `/audit` le voie) est traitée comme une vulnérabilité.

## Signaler une vulnérabilité

Merci de **ne pas ouvrir d'issue publique**. Utilisez le bouton *Report a vulnerability* de l'onglet **Security** du dépôt (signalement privé GitHub), ou le formulaire de contact de [braiinz.fr](https://braiinz.fr).

Indiquez la version du mod, la version de Claude Code et un exemple minimal. Une première réponse est donnée sous 7 jours.

## Versions suivies

Seule la dernière version de chaque mod reçoit des correctifs.
